# StockSense

StockSense is a modern Inventory Management System developed for the Odoo Hackathon.

The application provides a centralized platform for managing products, stock, receipts, deliveries, internal transfers, stock adjustments, warehouses, and inventory operations.

## Core Features

- User Registration and Login
- JWT-based Authentication
- Inventory Dashboard
- Product Management
- Stock Management
- Receipts and Incoming Stock
- Delivery Orders and Outgoing Stock
- Internal Stock Transfers
- Stock Adjustments
- Stock Ledger / Move History
- Warehouse and Location Management
- Low Stock Alerts
- Product Search and Smart Filters
- Inventory and Operation Status Tracking
