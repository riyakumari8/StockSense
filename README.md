# StockSense

StockSense is an Inventory Management System developed for the Odoo Hackathon.

## Core Features

- Product Management
- Stock Management
- Receipts
- Delivery Orders
- Internal Transfers
- Stock Adjustments
- Stock Ledger
- Warehouse and Location Management
- Inventory Dashboard
- Low Stock Alerts
- Search and Smart Filters

## Technology

- Odoo
- Python
- PostgreSQL
